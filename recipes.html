README

Thanks for checking out the generated recipes!

Recipe Model Outputs

  • The file titled "True Recipes" contains the gold recipes that were parsed from the datasets used in these experiments. They are not completely raw files and have gone through some pre-processing such as tokenizing words, removing uncommon words, and identifying phrases.
  • The file titled "True Recipes No Unknown" contains the same gold recipes as "True Recipes", except words that occur with low frequency have not been replaced by the "<UNK>" token
  • The "Checklist Model Generated Recipes" file contains recipes that were generated by the Checklist model described in the EMNLP 2016 paper, Globally Coherent Text Generation with Neural Checklist Models.
  • The "Checklist+ Model Generated Recipes" file contains recipes that were generated by the Checklist+ model described in the same paper.
  • The "Encoder-Decoder Model Generated Recipes" file contains recipes that were generated by the encoder-decoder baseline described in the same paper

Vocabularies

  • The file titled "Ingredient Vocabulary" contains all the words and composed phrases that appear as ingredients throughout all recipes of the training set.
  • The file titled "Title Word Vocabulary" contains all the words and composed phrases that appear in the titles of the recipes of the training set.
  • The file titled "Output Vocabulary" contains all the words and composed phrases that appear in the recipe steps of the recipes of the training set.
  • For any vocabulary, a word must occur at least 10 times in the training set to be included in that vocabulary.
